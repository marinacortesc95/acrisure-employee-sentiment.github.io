Review & Classification

Enter or import Glassdoor and Indeed reviews, classify them against the standing theme framework, check for duplicates, then export the processed dataset. The export file is the only thing that carries data to the dashboard.

1. Add reviews

Every review added here is classified against the framework straight away.
Classification runs on add, and it is rule-based — not a language model. Each review — title and text — is matched against the cue phrases behind every theme in the framework; sentiment comes from those cues (title wording weighted more heavily), the themes assigned, and the star rating when you give one; pros and cons are taken from the reviewer's own wording. It does not read context or catch sarcasm, so each result arrives as a suggestion with its confidence, and stays that way until you confirm it in the working set.
Read a review from a screenshot. Drop, choose or paste (Ctrl+V / ⌘V) a screenshot of one Glassdoor or Indeed review. Claude transcribes it into the review form (if Claude can't be reached — for example when this file is opened directly in a browser — it falls back to text recognition on your own device, which is less exact); nothing is added until you check the fields against the image and press Add review. Themes and sentiment are still assigned by the rule-based classifier afterwards.

3. Export processed dataset

Fixed column schema — the contract with the dashboard page.

Columns export in this order and are never renamed: Review Source, Review Date, Review Title, Sentiment, Primary Theme, Secondary Themes, Pros Summary, Cons Summary, Key Topics, Review Summary, Analyst Notes, Duplicate Flag, then the appended columns Location, Employment Status, Job Title and Star Rating. Earlier columns keep their original order and meaning, so exports made before the later columns existed (12 or 15 columns) still upload to the dashboard. Empty values export as N/A. Give each export a date so historical files stay distinguishable when you upload several at once.
